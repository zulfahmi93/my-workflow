5.1

DataUsageSnapshot + DataPlan core model (foundational gate)

flutter-expert architect: required (top) Closes: ADR-0011 + ADR-0012 — the pure-Dart data…

Pure-Dart foundation in lib/core (no widget code) modelling the EXTENDED GET /api/data-usage envelope (usage + plan), kept testable in test/core:

  • DataUsagePeriod — final int? rxBytes, txBytes; int? get totalBytes (rx+tx, absent side as 0 when the other has data; both-null → null); bool get hasData. Doc-comment: totalBytes = rx+tx within a period, distinct from DataUsageSnapshot.total (the firmware LIFETIME period). The MONTH period’s totalBytes is the cap-basis “Data Used”.
  • DataPlan — final int? monthLimitBytes, clearDay, remindPercent; parsed from the plan block (all nullable; null = firmware did not expose it). Doc-comment: read-only mirror of the modem’s Data Plan / Clear Date / Data Reminder; the app never writes these.
  • DataUsageSnapshot — final DataUsagePeriod day, month, total; final DataPlan plan; factory fromAgentJson(Map json). Envelope checks mirror clients_snapshot.dart: ok==true else AgentError; data Map else FormatException; a missing period/plan key → all-null sub-object (NO throw — the Reading stays FRESH). Tolerant _u64/_int extractor modelled on signal_snapshot’s parseInt.
  • Cumulative-counter rule (doc + test): a lower value on the next parse (cycle rollover on the Clear Date / firmware reset) is surfaced as-is — never negative, never accumulated; correct regardless of when firmware resets.

Optional refresh of lib/core/core.dart’s doc index. Keep lib/core import-clean. All prior core tests stay green.

Architecture review. required (top) — FOUNDATIONAL gate — touches data sourcing (the extended /api/data-usage contract). Locks: the parse contract (u64|null tolerant, rx=download/tx=upload, used = month rx+tx, cumulative NEVER-accumulate + surface-reset); the plan block contract (month_limit_bytes/clear_day/remind_percent, all nullable, agent-sourced read-only); binary IEC byte units (KiB/MiB/GiB/TiB labels) (5.2); DataUsageStatus math — over NOT clamped, divide-by-zero guard, NEAR keyed on remind_percent||80% on fractionUsed, OVER ≥100% (5.3); 30s cadence; full-width read-only section placement + no-scroll/no-RenderFlex re-gate + NO new IntrinsicHeight (5.5); red-token activation + two-tone DL|UL bar (5.4); per-tile freshness (ADR-0009); the NOT-security-tier ruling; and the agent-endpoint prerequisite (read-only wrapper, no app write). 5.2

formatBytes — binary IEC byte-volume helper

flutter-expert architect: none

Append formatBytes(int? bytes) to lib/core/format.dart (pure Dart). BINARY IEC tiers KiB=2^10, MiB=2^20, GiB=2^30, TiB=2^40, LABELED KiB/MiB/GiB/TiB (the modem’s values are binary; we print the honest IEC suffix, not the modem’s loose “GB”). Adaptive unit, FIXED precision per unit for tabular stability: <1024 → '<n> B'; <2^20 → 1dp KiB; <2^30 → 1dp MiB; <2^40 → 2dp GiB; else 2dp TiB. null OR negative → '—' (U+2014), never '0'. Existing formatRate/formatElapsedWindow tests stay green.

Architecture review. none — Single pure-function binary IEC byte-volume formatter (tiers 2^10/2^20/2^30/2^40, IEC labels KiB/MiB/GiB/TiB); deterministic, no I/O, no architecture surface; mirrors the existing formatRate. Unit/precision conventions pre-locked by the 5.1 verdict (ADR-0011); runs parallel in P5.A so cannot defer. Correctness gated by code-review. NOT security-tier.

5.3

flutter-expert architect: none

Create lib/core/data_usage_status.dart — pure Dart. A helper computing the plan status from the firmware-sourced used + plan: double? fractionUsed(int? usedBytes, int? monthLimitBytes) (null cap/used → null; monthLimitBytes <= 0 → null divide-by-zero guard; else used / cap, over-limit > 1.0 NOT clamped); int? percentUsed(...) (round(fraction*100), lower-clamp 0, no upper clamp — 254 allowed); bool isNear(...) ⇔ fractionUsed >= (remindPercent ?? 80)/100; bool isOver(...) ⇔ fractionUsed >= 1.0. Thresholds key on fractionUsed (double) so the displayed rounded % never contradicts the cue. Doc-comment the rules + byte-denomination.
