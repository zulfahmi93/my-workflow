Six cycles, two batches. The serial spine is just two cycles — 3.1 (the structural collapse, opus architect gate) then 3.5 (which shares lib/app.dart + test/app_flow_test.dart with the collapse). Batch B’s other four cycles (3.2, 3.3, 3.4, 3.6) are write-disjoint and can fan out in parallel after 3.1 lands. Each cycle is one fresh-context session per .claude/rules/cycle-orchestration.md §Session protocol; commit one cycle at a time after the human reviews the diff. ZERO new pubspec deps; ZERO security-tier cycles.

How to use

Run 3.1 alone first — it is the one architecture-gated cycle (opus) and it re-points the speed stream onto the generic Poller<T>; its blast radius (app.dart, speed_screen.dart, speed_history.dart, monitor_header.dart docs, core.dart barrel, three migrated test files) must land and go green before anything layers on top. Then fan out Batch B: 3.2 (signal-tile token), 3.3 (motion lifecycle), 3.4 (chart colours), 3.6 (status-strip finder) are mutually disjoint; 3.5 (client close) must follow 3.1 because it shares app.dart + app_flow_test.dart. No cycle is security-tier, so a single code-reviewer APPROVED is the gate (no security-reviewer second pass) — but the reviewer must still confirm 3.5 changes no auth path.

Common contract (applies to every session)

Every session: fresh context; read root /CLAUDE.md + projects/personal/u60-monitor/CLAUDE.md + the rules + this plan’s cycle entry; honour the architect-gate field (required only on 3.1); reviewer separation (never self-review); NO-DEFER on BLOCKER/REFACTOR; caveman tone is chat-only (code/tests/commits are idiomatic). No cycle adds a pubspec dep; no cycle adds a base-URL setter (either is an out-of-bounds STOP). Every commit subject is ≤50 chars (the “cycle X.Y — <long phrase>” pattern that tripped 2.14/2.15 is deliberately avoided — F8).

Worktree convention

Optional for the Batch B fan-out: one git worktree per cycle (.worktrees/u60-monitor-3.<n> on branch cycle/3.<n>) so the parallel sessions never touch each other’s tree. 3.1 and 3.5 run in the main tree (3.5 after 3.1). Sequential in-tree is also fine — concurrent flutter test can race .dart_tool, so serialise the test runs if sharing a tree.

Inter-batch verification

After 3.1 merges, run the full flutter test + flutter analyze (the latter must be “No issues found”, incl. zero dangling-doc-reference hints) before fanning out Batch B — every prior test plus the migrated tests must stay green with zero coverage loss. After each Batch B cycle merge, re-run the full suite + analyze. No cycle requires an on-device smoke; the deferred device smokes are a separate post-plan human deploy pass (see §Cycle follow-ups).

Stop conditions (across all batches)

Halt + write docs/AUTONOMOUS_RUN_STATUS.md on: architect NO-GO (3.1); a missing architect-gate field; a BLOCKER/REFACTOR needing genuine deferral; REVIEW still NEEDS FIX after 3 REFACTOR passes; the test gate unreachable for reasons outside the cycle; a pre-commit hook failure; a cycle demanding out-of-bounds changes (a new dep, a base-URL setter, an AgentClient AUTH-boundary edit). If 3.5 finds it must touch an auth/token/password/base-url path, it becomes security-tier — STOP and escalate (do not silently proceed). If poller_test.dart turns out NOT to be a superset of a speed_poller_test.dart case, keep speed_poller_test.dart (do not delete on a coverage gap) and STOP.

Final state

plan-003 done = the installable app behaves exactly as plan-002 shipped (no user-visible behaviour change) but with the debt paid: the speed stream runs on the single generic Poller<SpeedSnapshot> contract (the duplicated SpeedPoller skeleton + its redundant test deleted, zero coverage loss); the signal-tile stale dot uses the staleIndicator token like every other tile; one-shot motion snaps correctly on a runtime reduced-motion toggle and the recovery haptic is regression-locked; the chart painter cannot silently fall back to light-theme colours; the AgentClient http connection pool is released promptly on re-auth; and the StatusStrip count test is specific. Zero new deps; no auth path changed; the ADR-0002 base-URL invariant remains dormant and carried.
