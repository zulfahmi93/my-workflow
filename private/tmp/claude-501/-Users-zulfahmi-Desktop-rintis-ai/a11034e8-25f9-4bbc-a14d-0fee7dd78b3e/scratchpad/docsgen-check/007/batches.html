plan-007 replaces the first-load-only count-up with a faithful SwiftUI .contentTransition(.numericText()) morph on every value change, across every live numeric readout — motion decoded FROM the 169-frame capture (blur + scale + downward drift + asymmetric fade + left-to-right stagger + animated reflow; §Motion spec). One reusable primitive (7.1 pure-Dart glyph diff, arch-gated; 7.2 the core roll; 7.2b its blur + reflow + perf tiering) then adopted surface-by-surface (7.3 SpeedTwin + retire CountUpText, 7.4 BatteryTile, 7.5 DataUsageSection, 7.6 FooterTriplet + SpeedHistoryChart). ZERO new pubspec deps. No security-tier cycle. §Numeric-surface inventory is the completeness contract; 7.6’s REVIEW audits it.

How to use

Sequencing. Run SEQUENTIALLY on main, one commit per cycle: 7.1 (glyph diff, core, arch-gated opus) → 7.2 (core roll, defer) → 7.2b (blur + reflow + perf tiering, defer) → 7.3 (SpeedTwin adopt + retire CountUpText, defer) → 7.4 (BatteryTile) → 7.5 (DataUsageSection) → 7.6 (Footer + Chart, closes). 7.4/7.5/7.6 depend only on the finished widget (7.2b) and are file-disjoint, but are NOT parallelised: each cycle’s GREEN gate runs the whole flutter test suite, cross-attributable in a shared tree (the plan-004/005 lesson). Commit scopes: core (7.1), app (7.2–7.6).

Common contract (applies to every session)

Architect gate. 7.1 = required (opus) — the ONE gate; it locks the whole feature against the FRAME-ACCURATE §Motion spec (diff contract + single-controller roll + fixed top-enter + blur/scale/reflow/stagger + perf tiering + CountUpText retirement + ADR-0014). 7.2 + 7.2b + 7.3 = deferred to 7.1. 7.4/7.5/7.6 = none (mechanical adoption). MODEL-TIER POLICY: architect gate + ALL REVIEW on opus; RED/GREEN/REFACTOR default sonnet; never haiku. No security-tier cycle → no security-reviewer pass.

Workflow execution. Cycles run via .claude/workflows/tdd-cycle.js ({ project: "u60-monitor", projectPath: "projects/personal/u60-monitor", plan: "007", cycle, greenAgent: "Flutter Expert", redAgent: "Flutter Expert", securityTier: false }). The workflow returns a schema-validated record; the orchestrator files the cycle note (reviewer-agent-id = wf:<runId>/review-pass-<N>), updates status:, regenerates docs, and commits. Commits stay OUTSIDE the workflow. GOTCHA (carried from plan-006): the Workflow tool stringifies args for NAME-based invocations — use an inline wrapper script calling workflow('tdd-cycle', {realObjectLiteral}) so the args object never crosses the stringifying boundary.

Worktree convention

Not applicable — the cycles run sequentially on main, not in parallel worktrees. (Harness note, carried: isolation:worktree creates an app-less ROOT-repo worktree because /projects is gitignored at the root — the nested u60-monitor repo’s worktrees must be managed MANUALLY. Sequential-on-main sidesteps this entirely.)

Inter-batch verification

After each cycle: full flutter test green + flutter analyze clean + a fresh code-reviewer (opus) APPROVED; a manual UI smoke of the changed surface (morph on value change, no 0 flash, reduced-motion instant); update the cycle status: in plan-007.yaml; file docs/cycles/7.X.yaml (npm run validate-cycle-note); regenerate docs (npm run build -- u60-monitor; html/ gitignored). One commit per cycle per commit.md.

Stop conditions (across all batches)

  • 7.1 architect returns NO-GO, or requires a NEW pubspec dependency (the morph must be buildable from framework primitives — a package add is out-of-bounds) → STOP, escalate.
  • Any dependencies: add (none planned) → out-of-bounds STOP.
  • Any existing test weakened to fit the new motion, or a composed Semantics label broken (a11y regression) → STOP / BLOCKER.
  • A flutter/material/dart:ui import appears under lib/core/ (7.1) → BLOCKER.
  • An adoption cycle introduces a new overflow (the morph defeating a FittedBox at 360dp / 1.3×) → BLOCKER, fix in-cycle.
  • Dead code left after 7.3 (an orphaned CountUpText reference or test) → [REFACTOR], fix before COMMIT.

Final state

Test trajectory: baseline 322 → roughly +8 (7.1) +7 (7.2 core roll) +4 (7.2b blur+reflow) +4 (7.3, net of migrated CountUpText cases) +3 (7.4) +4 (7.5) +3 (7.6) ≈ ~355 tests. ZERO new deps. No git remote — never push.
