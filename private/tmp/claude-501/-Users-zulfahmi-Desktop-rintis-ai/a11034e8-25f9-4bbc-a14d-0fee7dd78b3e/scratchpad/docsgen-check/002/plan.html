2.1

Generic Poller<T> + Reading<T> core scaffolding (foundation)

flutter-expert architect: required (mid) Closes: new — the generic polling skeleton every…

Foundation cycle (the ONE sanctioned pubspec-touch point — adds NO deps). Extract a generic pure-Dart Poller<T>({required AgentClient client, required String path, required Duration interval, required T Function(Map<String,dynamic>) parse}) into lib/core/poller.dart, emitting Reading<T>{ T? snapshot, bool isStale, Object? error } (lib/core/reading.dart), replicating SpeedPoller’s exact contract verbatim:

  • Timer.periodic(interval, _tick) started in the ctor; each tick client.getJson(path) → parse(map) → emit Reading(snapshot, isStale:false, error:null) + cache _last.
  • broad catch (e) → emit Reading(_last, isStale:true, error:e) — keep last-known, NEVER emit a fake 0, stream STAYS OPEN (next tick can recover).
  • AUTH-HALT: if e is AuthFailure || e is AuthRequired → also _timer.cancel() (stops the ~1 login/sec self-DoS) but do NOT close the controller (caller reads the terminal error, disposes, rebuilds).
  • dispose() cancels timer + closes controller, idempotent.

Pure Dart only (Timer + injected clock; no flutter/material/dart:ui). Leave SpeedPoller/SpeedReading EXACTLY as-is — add Poller<T> alongside (collapsing SpeedPoller onto Poller<SpeedSnapshot> is a tracked future follow-up, NOT this cycle). Files docs/adr/0005-multi-metric-polling.md.

Architecture review. required (mid) — generic Poller<T> + Reading<T> shared skeleton replicating SpeedPoller’s broad-catch keep-last-known + auth-halt + idempotent-dispose contract verbatim; this is the foundation/sanctioned-pubspec cycle but adds zero deps; the contract it locks is reused by every metric

2.5

sparklinePoints pure geometry function

flutter-expert architect: none Closes: new — the geometry the SpeedHistoryChart…

lib/core/sparkline_geometry.dart — pure List<(double dx, double dy)> sparklinePoints(List<double> series, double width, double height, {double? min, double? max}). Returns plain (double,double) records and takes width/height as doubles — does NOT use dart:ui Offset/Size (banned in lib/core/); the CustomPainter (2.10) maps records→Offset in lib/ui/.

Maps the series across [0, width] on dx and inverts/scales the value onto [0, height] on dy (screen-y grows downward). Shared auto-range to the rolling max with a sensible FLOOR (the value-space ceiling never drops below ~10 Mbps-equivalent so a quiet idle link doesn’t amplify noise into mountains); min/max override the auto-range. Guards: min==max divide-by-zero (points on a mid/baseline); NaN/Inf clamped/skipped, never propagated; empty → empty; single point at baseline.

Architecture review. none — pure geometry function exhaustively unit-tested in core; returns plain (double,double) records (not dart:ui Offset/Size, banned in core); the painter merely consumes it.
