Context

plan-002 is the Glance-Dashboard extension of the plan-001 live-speed MVP. It adds, on the SAME single Samsung-S22 portrait screen (no subpages, no tabs, ideally no scroll):

  1. History graph — a client-side dual sparkline of upload + download over a rolling 2-minute window (120 samples @ ~1s). There is no server history endpoint (confirmed by grep of the agent source) — history is built client-side from the existing 1s speed feed, exactly as the official iOS app does.
  2. Battery — SoC % + charge state, incl. “Charging paused (cap N%)”, read from GET /api/device/charge-control.
  3. Signal — derived 4G / 5G network type + strength (RSRP / SINR / bars) from GET /api/network/signal.

Plus three cheap bonus glance fields: operator name + roaming (free inside the signal payload), modem uptime (GET /api/device), and connected-client count (GET /api/network/clients).

Design thesis (3-agent fan-out: architect + UI/UX + Flutter feasibility, strong consensus). ZERO new pubspec deps — the chart is a hand-rolled dual-sparkline CustomPainter (not fl_chart), history is an in-memory ring (not persisted), and multi-metric polling is a generic pure-Dart Poller<T> added additively so the existing SpeedPoller and its 59 green tests are untouched. All new endpoints are read-only GETs reusing the audited Cycle-1.4 AgentClient lazy-auth boundary verbatim (same Bearer token, same {ok,data} envelope, same typed-exception taxonomy) → no feature cycle is security-tier. Features ship FIRST; a UI/UX refinement batch (motion, theming) runs LAST.

Agent contract additions (verified against ~/Desktop/tools/open-u60-pro source — the spec, do not guess):

  • GET /api/device/charge-control → {ok:true,data:{charging_stopped:bool, battery_status:String, capacity:i64, charge_limit_enabled:bool, charge_limit:int, hysteresis:int, manual_override:bool}}. Always 200 (sysfs reads). capacity = SoC %; battery_status = Linux enum (Charging|Discharging|Full|Not charging|Unknown); charging_stopped && charge_limit_enabled ⇒ “paused at charge_limit%”. (device_ext.rs L44-78.)
  • GET /api/network/signal → raw ubus pass-through; values arrive as STRINGS (“-95”,“4”), ""/"--"/"N/A" = absent, rsrp 0 = not connected, |v|>9000 = sentinel-null. 4G/5G is derived (nr5g_rsrp present & non-zero ⇒ 5G; firmware network_type lies “LTE” under 5G NSA → override; lteca ⇒ 4G+). 503 on ubus failure → stale. (handlers.rs L102-107; field map = iOS SignalParser.)
  • GET /api/device → {ok:true,data:{hostname, uptime_secs, load_avg, kernel}} (uptime). (handlers.rs L59-70.)
  • GET /api/network/clients → {ok:true,data:{hosts, dhcp_leases:[...]}}; connected count = dhcp_leases length; surface the COUNT only, never MAC/IP. (network_ext.rs L27-39.)
  • GET /api/network/speed (unchanged) — cheap in-memory snapshot, ~1s, feeds the history ring.

Honest scope note (user-confirmed): the firmware battery contract has no “idle” / “power-saver” status — that was the original feature ask, but it does not exist (power-save is an unrelated writable setting). The user opted to surface charge-cap pause instead, via /api/device/charge-control. Recorded in ADR-0006.

Security posture (unchanged): never WAN-expose the agent; password stays in flutter_secure_storage; bearer tokens never logged; ADR-0002 base-URL invariant carries forward — plan-002 adds NO base-URL/Settings setter, which keeps the whole plan out of the security tier. If a future cycle ever adds one, that cycle is security-tier and must validate http(s)+private/LAN-host in-cycle.

Architecture rule (unchanged + enforced): all new models, pollers, the ring, and the sparkline geometry live in lib/core/ as pure Dart (no flutter/material/dart:ui). The geometry fn returns plain (double,double) records — not Offset/Size (banned in core); the painter maps records→Offset in lib/ui/. A flutter import under lib/core/ is an instant review BLOCKER. Widgets/painter live in lib/ui/; composition in lib/app.dart.

No new pubspec deps. Per the plan-001 frozen-pubspec rule, Cycle 2.1 is the sole sanctioned pubspec-touch / foundation cycle (mirroring 1.1’s role) — but it adds zero deps (it is shared core scaffolding). Any mid-plan dep add is an out-of-bounds STOP.

Out of scope (plan-002)

  • Persisted history — the ring is in-memory only; the chart repopulates within its 2-min window on relaunch. Persistence (hive/sqlite) adds disk I/O, serialization bugs, a data-at-rest surface, and stale-on-launch ambiguity for zero glance value (ADR-0003). Rejected by all three designers.
  • fl_chart / any charting dep — the dual sparkline is a CustomPainter; fl_chart is the single sanctioned fallback and could only enter via Cycle 2.1, never mid-plan (ADR-0004).
  • A base-URL / Settings setter — deliberately not added (keeps the whole plan out of the security tier per ADR-0002). If ever added, that cycle is security-tier with in-cycle http(s)+private/LAN validation.
  • Battery “idle / power-saver” status — not in the firmware contract; power-save is a separate writable ubus setting. Charge-cap pause IS surfaced via /api/device/charge-control (ADR-0006).
  • CA / carrier-aggregation detail (nrca/lteca semicolon CSV), cell IDs, band-lock, SMS, router config — the 143-endpoint control surface stays with open-u60-pro’s native apps.
  • WiFi-key / /api/wifi/status as the clients source — it would pull the WiFi PSK over the wire; /api/network/clients (DHCP leases) gives the count with no secret leak.
  • Remote / away-from-modem access — unchanged security hazard; never WAN-expose.

Conventions in play

Every cycle runs through the same disciplined loop, defined in the shared rules under .agents/rules/.

Architect gate

Each cycle carries an architecture-review tier (top, mid, none, or deferred). Legacy provider aliases are normalized while loading. A fresh software-architect returns a GO / NO-GO verdict before RED for the non-trivial ones.

Reviewer separation

REVIEW is performed by a fresh code-reviewer sub-agent — never self-review. Security-tier cycles add a security-reviewer second pass.

NO-DEFER

Every [BLOCKER] and [REFACTOR] finding is resolved in the same cycle’s REFACTOR pass. Scope discipline is not a reason to defer an in-scope finding.
