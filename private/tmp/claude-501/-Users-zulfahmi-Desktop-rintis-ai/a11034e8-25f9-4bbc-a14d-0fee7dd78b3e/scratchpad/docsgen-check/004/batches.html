Ten cycles, five batches. Foundations first (core display logic ‖ offline fonts), then the theme token system (the single gate every UI cycle waits on), then five file-disjoint component cycles, then the chart data contract, then screen assembly + cleanup. The serial spine is 4.2 → 4.3 → 4.6 → 4.7 → 4.10; everything else fans out around it. Each cycle is one fresh-context session per .claude/rules/cycle-orchestration.md §Session protocol; commit one cycle at a time after the human reviews the diff. ZERO new pubspec PACKAGE deps (fonts are local assets); ZERO security-tier cycles.

How to use

Run P4.A first: 4.1 (pure-Dart chart display logic — opus gate) and 4.2 (offline fonts — opus gate) are file-disjoint and can run concurrently. Then 4.3 alone (the theme token system — opus gate) — every UI cycle depends on it. Then fan out P4.C: 4.4 (header), 4.5 (twin), 4.6 (chart-visual), 4.8 (battery), 4.9 (footer) are mutually file-disjoint; 4.4 + 4.7 are the required-gate members. Then 4.7 (P4.D) — it shares speed_history_chart.dart with 4.6, so it MUST land after 4.6. Finally 4.10 (P4.E) — it depends on every component cycle and owns the deletions + per-tile feed-state wiring. No cycle is security-tier, so a single code-reviewer APPROVED is the gate (no security-reviewer second pass).

Common contract (applies to every session)

Every session: fresh context; read root /CLAUDE.md + projects/personal/u60-monitor/CLAUDE.md + the rules + this plan’s cycle entry; honour the architect-gate field (required on 4.1/4.2/4.3/4.4/4.7/4.10, none on 4.5/4.6/4.8/4.9); reviewer separation (never self-review); NO-DEFER on BLOCKER/REFACTOR; caveman tone is chat-only (code/tests/commits idiomatic). No cycle adds a pubspec PACKAGE dep (4.2’s fonts: + assets is the ONLY pubspec touch; a dependencies: add is an out-of-bounds STOP); no cycle adds a base-URL setter. Every commit subject is ≤50 chars.

Worktree convention

Recommended for the P4.C fan-out: one git worktree per cycle (.worktrees/u60-monitor-4.<n> on branch cycle/4.<n>) so the parallel sessions never touch each other’s tree — and so a whole-project flutter analyze isn’t cross-attributable between concurrently-edited cycles (the plan-005/kobu lesson: parallel cycles in ONE tree make tsc/analyze cross-attributable). 4.1/4.2/4.3 and 4.7/4.10 are serial points; run them in the main tree. Concurrent flutter test can race .dart_tool, so serialise the test runs if sharing a tree.

Merge protocol

Linear history preferred (the plan-003 lesson): land each cycle as a single commit on main (or cherry-pick the worktree branch’s single commit onto main) rather than --no-ff merge bubbles. The root Claude hook blocks --amend/--no-verify — never use them; fix-forward with a new commit. One cycle = one commit (code + plan status: + cycle note).

Conflict notes from source

Inter-batch verification

After 4.1 + 4.2 merge, run full flutter test + flutter analyze (the latter “No issues found”). After 4.3, re-run the full suite (additive — nothing should break). After EACH P4.C cycle merge, re-run the full suite + analyze (each adds a new widget/test; the old screen still uses the old widgets, so all prior tests stay green). After 4.7 (chart contract) and 4.10 (assembly + deletions), the full suite + analyze must be green with zero dangling refs. No cycle requires an on-device smoke; the device-verify pass is a separate post-plan human deploy (see §Cycle follow-ups).

Stop conditions (across all batches)

Halt + write docs/AUTONOMOUS_RUN_STATUS.md on: architect NO-GO (4.1/4.2/4.3/4.4/4.7/4.10); a missing architect-gate field; a BLOCKER/REFACTOR needing genuine deferral; REVIEW still NEEDS FIX after 3 REFACTOR passes; the test gate unreachable for reasons outside the cycle; a pre-commit hook failure; a cycle demanding out-of-bounds changes (a new PACKAGE dep, google_fonts, a base-URL setter, an AgentClient auth-boundary edit, a global feed-state instead of per-tile). If a 1.3x-font-scale RenderFlex overflow in 4.10 cannot be resolved without a layout compromise, STOP and surface the UX call. If tabular figures cannot survive any shippable Space Grotesk instance in 4.2, STOP and escalate the font-source decision.
