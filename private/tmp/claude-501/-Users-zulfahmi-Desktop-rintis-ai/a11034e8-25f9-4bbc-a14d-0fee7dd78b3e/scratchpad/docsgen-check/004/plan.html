4.1

Core chart display logic — x1.12 headroom, peak getter, mm:ss window

flutter-expert architect: required (top) Closes: ADR-0007 CYCLE A — the pure-Dart display…

Pure-Dart foundation in lib/core (no widget code) so the new chart display values are testable in test/core, kept out of the painter:

  • sparklinePoints x1.12 headroom (lib/core/sparkline_geometry.dart) — the auto-range ceiling currently equals the raw window max (or the hysteresis-held value); the redesign normalizes to max(down, up) * 1.12 so the peak line never touches the top edge. Apply the multiplier at the ceiling computation; keep the existing min/max override path and the non-stale-only derivation.
  • SpeedHistory.peakBytesPerSec (lib/core/speed_history.dart) — a getter over the 2-minute ring returning the window max across non-stale samples (the larger of down/up per sample), 0.0 when the ring is empty or all-stale. This is the value the chart surfaces as “PEAK {n} Mbps” (÷1e6 in the UI); compute it in core, not the widget.
  • formatElapsedWindow(samples) (lib/core/format.dart) — a pure mm:ss formatter for the chart’s left-edge label: −2:00 once the ring is at capacity, the real partial delta (−0:42) until it fills, derived from the oldest vs newest tMillis. Defined boundary behaviour: empty ring, single sample, all-stale.

Keep lib/core import-clean (a flutter/material/dart:ui import here is an instant BLOCKER). All prior sparkline_geometry/speed_history/format tests stay green with zero coverage loss.

Architecture review. required (top) — Foundational chart data contract + newly surfaced display data (peak, dynamic time-axis) = ‘touching data sourcing’ per the required-gate rule. Gate confirms: lib/core stays flutter/material/dart:ui-free; the max(down,up)*1.12 ceiling is correct and the never-lie stale-gap invariant (ADR-0003/0004) is untouched; peakBytesPerSec reads ONLY non-stale samples; the mm:ss elapsed-window formatter is a pure function with defined empty/partial/full/all-stale behaviour. Opus per the model-tier override (arch gates = opus).
